WebNovel Dark & Enhanced

A real dark theme, readable card listings, tag / book / author filters and a reader with a searchable table of contents — for webnovel.com.

Free · Open source · No tracking · Works in Chrome, Edge and Brave (111+)

Everything the site should have

Built on the site's own CSS variables, so dialogs, dropdowns and lazy-loaded pages keep up.

Dark, Midnight & Dim

Three palettes and four accents. No inverted images or broken brand colours.

Clean listings

Cover-grid cards capped at five per row, with tags, descriptions and ratings.

Filters on the page

Hide or prefer a tag from its chip, block books from a card, block authors from their profile.

Whole-catalogue author blocks

Blocking an author imports every book on their profile and refreshes it daily.

A better reader

Width, font, size, line height, progress, scroll memory and chapter hotkeys.

Searchable TOC

Volume-grouped table of contents with locked badges, type-to-filter and instant opening.

Install

The extension is distributed through GitHub releases. A Chrome Web Store listing is in progress.

Download and extract

Get the latest webnovel-dark-enhanced-<version>.zip from Releases and unpack it, or clone the repository.

Open your extensions page

chrome://extensions · edge://extensions · brave://extensions

Enable Developer mode and Load unpacked

Select the folder containing manifest.json. Pin the extension, then open webnovel.com.

Updating: replace the files (or ./tools/update.sh), click Reload on the extension card, and refresh the site tab. The extension also shows an ↑ badge when a newer release is published.
